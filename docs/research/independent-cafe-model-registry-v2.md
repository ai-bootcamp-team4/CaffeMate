# 개인카페 모델 레지스트리 v2 조사 기준

## 목적

CaffeMate의 Proposal Agent가 개인카페 유형을 처음부터 지어내지 않도록, 조사 근거가 있는 운영 모델과 비용 범위를 먼저 등록한다. Agent는 등록된 모델 중 사용자 조건과 상권에 맞는 후보를 해석하고 조정하며, 비용 계산과 최종 순위는 Control API가 담당한다.

## 적용 원칙

- `FACT`: 공식 조사나 공개 자료에서 직접 확인한 값이다.
- `INFERENCE`: 여러 조사값을 카페 유형에 맞게 나누거나 계산한 값이다.
- `PROVISIONAL_ASSUMPTION`: 실제 점포나 견적이 들어오기 전까지만 사용하는 임시 범위다.
- 보증금, 월세, 관리비, 권리금, 공사비, 장비비는 실제 자료가 들어오면 즉시 교체한다.
- 권리금이 없는 점포도 있으므로 모든 유형의 최솟값은 0원이다.

## 등록 유형

| 구분 | 모델 | 기본 추천 | 여는 조건 |
|---|---|---:|---|
| 일반 | 가치·속도 회전형 | 예 | 포장·회전·낮은 가격 선호 시 우선 |
| 일반 | 생활권 단골 균형형 | 예 | 동네·주거·단골 선호 시 우선 |
| 일반 | 체류·작업 좌석형 | 예 | 좌석·공부·작업 선호 시 우선 |
| 일반 | 스페셜티 품질형 | 예 | 원두·핸드드립·로스터리 선호 시 우선 |
| 조건부 | 디저트·베이커리 결합형 | 아니요 | 자기자금 2억5천만 원 이상이며 관련 선호나 경험을 명시 |
| 조건부 | 목적지·경험형 | 아니요 | 자기자금 2억5천만 원 이상이며 관광·전망·체험 등 방문 이유를 명시 |

조건부 모델은 입력이 부족한 상태에서 비용만 큰 일반 카페로 추천되는 일을 막기 위해 기본 후보에서 제외한다.

## 조사 기준값

- `FACT` 2025년 비프랜차이즈 비알코올 음료점업의 평균 신고면적은 75.4㎡, 대표자 포함 월평균 근로자는 2.12명이다.
- `FACT` 같은 업종의 연평균 매출은 1억3,760만 원이며, 식재료비는 매출의 38.1%, 임차료는 9.2%, 영업이익률은 9.8%다.
- `FACT` 같은 업종의 평균 개업 투자비는 7,388만 원, 인테리어는 4,125만 원, 주방·장비 관련 비용은 2,346만 원이다. 이 값은 보증금과 권리금, 운영자금을 모두 포함한 총 필요자금으로 사용하지 않는다.
- `FACT` 한국부동산원의 2025년 4분기 서울 소규모 상가 월환산 임대료는 ㎡당 5만2,200원이다.
- `FACT` 2025년 서울 상가 평균 권리금은 4,938만 원이지만 권리금이 있는 점포 비율은 54.85%다.
- `FACT` 2026년 최저임금은 시간당 10,320원이다.
- `INFERENCE` 식재료비에 카드 수수료, 포장재, 판매 연동 소모품을 더한 개인카페 공헌이익률 기준 범위는 약 55~63%다.

## 비용 범위 해석

레지스트리의 모든 비용은 원 단위의 `low / base / high`로 저장한다. 공사비에는 기본 인테리어, 전기·급배수, 바, 고정가구와 기본 간판을 포함한다. 장비비에는 커피 장비, 제빙·냉장 장비, 쇼케이스와 유형별 필수 장비를 포함한다.

다음 비용은 점포 상태에 따라 상한을 넘어갈 수 있다.

- 철거
- 전기 증설
- 덕트와 환기
- 소방 설비
- 건물 구조 변경
- 영업 제한을 해결하기 위한 추가 시설

점주 본인의 목표 급여는 현재 월 인건비에 포함하지 않는다. 실제 검토 단계에서는 `owner_compensation_target`을 별도 비용으로 추가해야 한다.

## 추천 연결

```text
Founder State
→ 운영 방식과 자기자금으로 불가능한 모델 제거
→ 명시한 선호와 경험으로 관련 모델 우선 배치
→ 조건부 모델은 관련 관심을 명시한 경우에만 개방
→ 상위 세 모델을 세 Proposal Agent가 각각 평가
→ Control API가 등록 비용으로 재무 계산
→ Candidate Auditor가 근거와 과장 여부 확인
→ 최대 세 후보 결과 카드
```

Agent가 바꿀 수 있는 것은 좌석 수, 포장 비중, 메뉴 복잡도, 영업시간, 운영 인원 같은 허용 범위 안의 제안뿐이다. 등록 비용, 자금 충족 여부, 손익분기 계산과 최종 순위는 Agent가 변경하지 않는다.

## 실제 값 교체 순서

1. 실제 점포의 보증금·월세·관리비·권리금
2. 철거·전기·급배수를 포함한 공사 견적
3. 장비 견적
4. 근무표와 임금
5. 메뉴 원가표와 판매 비중
6. 나머지 레지스트리 가정

## 한계

- 공식 업종 통계에는 개인카페 외 다른 비알코올 음료점이 일부 포함된다.
- 개업 투자비 응답에는 금액을 모른다는 응답이 많아 범위가 넓다.
- 포장 비중, 메뉴 복잡도와 유형별 공헌이익률은 직접 측정한 공공 자료가 부족하다.
- 임대료와 권리금 통계는 개별 매물 가격이 아니므로 상권과 층, 점포 상태에 따라 크게 달라질 수 있다.

따라서 첫 결과는 창업비 확정 견적이 아니라 비교 가능한 출발점이다. 실제 점포와 견적이 들어오면 같은 계산 구조에서 값을 교체해 다시 판단한다.
