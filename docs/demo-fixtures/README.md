## 공통 시나리오

- 지역: 서울특별시 마포구 공덕동

- 운영안: 중소형 균형 개인카페

- 점포 조건: 보증금 30,000,000원, 월세 2,200,000원, 관리비 200,000원, 권리금 10,000,000원

각 PDF의 첫 줄, 페이지 상단, 마지막 주의사항에 데모 전용 표시가 반복됩니다.

## 발표 시 확인할 결과

1. PDF 업로드가 완료되고 문서 상태가 `EXTRACTION_READY`로 바뀐다.
2. 추출 폼에 위의 핵심 값이 자동으로 채워지고 사용자가 수정할 수 있다.
3. 적용 후 선택 후보가 유지되고 재계산 워크플로가 완료된다.
4. 점포 문서는 보증금·월세·관리비·권리금의 기존 참고값을 문서 확인값으로 교체한다.
5. 실제 문서가 아니라는 경고는 결과 계산의 근거 상태와 별도로 명확히 표시한다.
